💧 AquaLoop

Measure. Understand. Reduce.

AquaLoop is a lightweight water-use intelligence prototype designed to help people understand everyday water consumption, identify major sources of estimated use, and make practical conservation decisions.

🌊 What AquaLoop Does

AquaLoop currently provides:

- 💧 Daily water-use estimation
- 📊 Weekly and monthly projections
- 🔎 Activity-level water-use breakdown
- 💡 Personalized conservation recommendations
- 💾 Local history using browser storage
- 🎯 User-defined water-reduction goals
- 📈 Goal-progress tracking
- 📱 Responsive mobile-friendly interface

🧮 Current Water-Use Model

The prototype estimates water use from four activities:

Activity| Prototype estimate
Shower| 9 L/min
Toilet| 6 L/flush
Laundry| 60 L/load
Dishwashing| 6 L/min

These values are simplified prototype assumptions and should not be interpreted as precise measurements. A future version can incorporate validated, region-specific data and fixture/appliance characteristics.

🛠️ Technology

AquaLoop currently uses:

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

No external framework or backend is required for the current MVP.

🔐 Privacy

The current prototype stores saved water-use records locally in the user's browser using LocalStorage.

No account or server-side database is currently required.
